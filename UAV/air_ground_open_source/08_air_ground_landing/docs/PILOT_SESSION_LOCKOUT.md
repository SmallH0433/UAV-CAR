# 人工接管会话锁存

2026-09-08 源码加固，适用于原生 LAND 和 companion GUIDED 两条执行路径。

飞控报告非当前模式事务预期的模式变化后，执行器立即清除模式事务及自动会话。即使飞手切到 ALT_HOLD/LOITER、RC6 和 CH8 一直高位，也不重新请求 GUIDED、不发送自动 setpoint 或普通 DISARM。撤销中的回退事务也受此规则约束。

重新启用操作：保持飞控连接、已解锁且 State 新鲜；RC6 回低并持续收到至少跨越 0.4 秒的低位样本，然后在 ALT_HOLD/LOITER 且旧模式事务已结束时拨高。单个低位样本等待 0.4 秒无效，中立区、RC 断流或低位采样间隔超过 0.5 秒会清除确认。过早拨高不会排队，需重新低→高。启动、重启、断连、上锁或 State 超过 2 秒不更新后，也需要新授权。

保持 `require_rc_authorization=true`；RC6 会话仍需低→高授权。CH8 为高电平降落请求：确认跟飞且 RC6 会话有效时，高位直接请求，无需 CH8 低→高确认。详见 [CH8 当前逻辑](./CH8_SESSION_CONFIRMATION.md)。

后续本地加固：RC 回调逐条处理样本，两个控制周期之间的高位/中立脉冲也会中断低位确认。高位必须是晚于最后低位的独立新样本，且间隔不超过 0.5 秒；本节点接收时间无效、未来、过期或倒退时不授权。重新确认期间外部切模同样清除已累计的低位证据。模式命令在实际发送前再次检查当前请求序号和会话；保留本事务的撤权回退，不发送已取消或被替换的请求。

正常由本执行器发起并等待确认的 GUIDED/LAND/回退模式变化不被当作外部接管。主动 RC6 撤权仍允许原有已拥有会话的回退流程；外部模式接管会取消该流程。启动时发现已有 GUIDED 不取得控制权，也不启动“孤立 GUIDED 回退”。

状态主题新增 `pilot_session_authorized`、`pilot_session_reason`、`pilot_session_sequence`。序号仅在本进程内递增，不是跨节点协议或持久化会话 ID。

限制：本修复针对飞控已报告的外部模式变化，不新增摇杆接管识别。已发往飞控的模式命令无法通过取消 Python 回调撤回；晚到心跳不会恢复被撤销会话，但在途命令可能造成一次延迟模式变化。飞手与本节点恰好请求同一目标模式时，仅凭 State 无法辨别来源。实机必须验证这些竞态及独立 RC/飞控保护；不能将本地测试当作实飞验收。

测试：`test_pilot_session.py` 测试纯会话门控，并直接执行源码中的状态回调、会话门控、旧模式出口与 GUIDED 周期方法，使用内存模拟消息/输出，不导入 ROS、不连接飞行器。另保留 `test_pilot_mode_gate.py` 的底层事务检查。完整 Python 套件 106 项通过，另有 1 项 OpenCV 图像解码测试在不含 OpenCV 的环境中跳过。

部署时必须同步更新 `guided_execution.py` 与 ROS 包 `guided_executor.py`，重新构建或更新实际挂载的发布文件。历史 `flight_logs/` 下的快照不应被修改。当前验证以离线测试和未解锁地面检查为主；已解锁接管、在途模式命令竞态与完整起降流程仍需实机验收。

# 垂直保护 shadow 模式说明（2026-10-06）

## 当前状态

垂直保护在实机配置中固定为 `shadow`。它计算并发布垂直健康状态、状态转换、时间戳质量和持久化锁存诊断，但不会因为新检测到的垂直异常自动切换飞行模式、发送速度命令、解除控制权或触发紧急停机。

当前实现包括：

- 使用真实的传感器和相机采集时间，而不是轮询到达时间构造新证据；
- 对未知、陈旧、越界和不连续的垂直证据保持失效关闭；
- 将垂直健康状态和转换原因加入执行器状态与 HTTP 状态输出；
- 提供持久化故障锁存和显式复位接口，为后续受控启用做准备；
- 保持现有飞手授权、模式门控、单写入者和输出开关不变。

## 为什么不启用 enforce

飞控侧垂直异常的根因和完整接管链尚未完成受控验证。启用自动干预前，至少需要完成故障注入、SITL、拆桨台架、模式回执、复位流程和飞手接管测试，并确认错误检测不会引入新的模式振荡或控制竞争。

因此，`enforce` 不属于本次发布范围；不得仅通过修改一个配置值在实机上直接启用。

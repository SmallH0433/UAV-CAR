# ESP8266 双 T8 双向丝杆步进驱动（下位机）

ESP8266 作为树莓派 4B（ROS 2 Humble）的下位机，驱动两个 42 步进电机，
分别控制两根 T8 双向丝杆。电机双出轴位于丝杆中点，左端正牙、右端反牙，
电机转动时两侧螺母反向等速移动。每个控制组 = 电机 + 丝杆 + 左右两个螺母。

- 导程：2 mm（单头，转一圈螺母移动 2 mm）
- 单边行程：67 mm = 33.5 圈
- 默认 8 细分 → 53600 步/全程（按驱动板拨码修改 `MICROSTEPS`）

## 状态机（每个控制组独立）

```
AT_OUTER(外侧自锁) --IN-->  MOVING_IN  --到位--> AT_INNER(内侧自锁)
AT_INNER           --OUT--> MOVING_OUT --到位--> AT_OUTER
运动中 STOP --> HOLD_MID(原地自锁)，之后可继续 IN/OUT 走完剩余行程
```

自锁 = 保持 EN 使能，电机带保持转矩。T8 2mm 导程本身机械自锁，
保持使能用于消除齿隙游动；发热敏感时可用 `RELAX` 释放使能。

## 接线

每个电机驱动板 4 根杜邦线（STEP/DIR/EN/GND，如 TB6600/DM542/A4988）：

| 信号 | 电机1（控制组1） | 电机2（控制组2） |
|------|-----------------|-----------------|
| STEP | IO13            | IO15            |
| DIR  | IO12            | IO4             |
| EN   | IO14            | IO2             |
| GND  | GND             | GND             |

选脚理由：IO15 上电为低（STEP 空闲低）；IO2 上电为高（EN 低有效 → 上电即失能，安全）；
IO0 是启动模式脚，接外设容易卡住烧录，刻意不用。

保留/备用：

- TXD/RXD：树莓派 4B 串口命令链路（ROS 2 接口）
- IO5、IO16、ADC：备用

## 串口协议（ROS 2 接口）

115200 8N1，每行一条命令，大小写不敏感。

| 命令 | 说明 |
|------|------|
| `IN 1` / `IN 2` / `IN` | 组1 / 组2 / 两组同时 向内运动 67mm |
| `OUT 1` / `OUT 2` / `OUT` | 向外运动 67mm（回到外侧） |
| `STOP` | 两组立即停止，原地自锁（HOLD_MID） |
| `RELAX [1\|2]` | 释放使能（不再自锁，省电降温） |
| `LOCK [1\|2]` | 恢复使能（自锁） |
| `SPEED <50..20000>` | 设置脉冲频率 steps/s（默认 1600 = 2mm/s） |
| `POS` / `STATUS` | 查询两组状态与位置 |

应答与上报：

- `OK ...` / `ERR ...`：命令应答
- `DONE G1 IN pos=67.00mm`：运动到位主动上报
- `POS` 返回示例：`G1 state=MOVING_IN pos=12.75mm steps=10203 en=1`

## 编译与烧录（Windows）

PlatformIO 安装在独立虚拟环境，不依赖系统 PATH：

```bash
PIO="D:\Codex\tools\esp8266-venv\Scripts\pio.exe"
cd D:\Codex\tools\leadscrew42
$PIO run             # 编译
$PIO run -t upload   # 烧录（自动检测串口，当前为 COM7）
```

## 关键配置（src/main.cpp 顶部）

| 宏/常量 | 默认 | 说明 |
|---------|------|------|
| `MICROSTEPS` | 8 | **必须按驱动板拨码核对**，否则行程不是 67mm |
| `DIR_IN` | `HIGH` | DIR 电平与"向内"的对应关系，实际反向就改成 `LOW` |
| `EN_ACTIVE_LOW` | 1 | EN 低电平使能（TB6600/DM542/A4988 均如此） |
| `DEFAULT_SPEED` | 1600 | 脉冲频率 steps/s，1600 = 2mm/s，全程约 33.5s |

## ROS 2 对接示例

树莓派侧 Python 节点：打开 `/dev/ttyUSB0`@115200，订阅目标话题后发送
`IN 1\n` 等文本命令；解析串口回传的 `OK/DONE/ERR` 和 `POS` 状态行，
发布到状态话题。

## 注意事项

1. **上电默认假定螺母处于外侧（pos=0）**。实际不在外侧时请先手动归位再上电。
   长期建议加装限位开关做归零。
2. 电机为 12V 额定。驱动板若用 24V 供电，电流档必须按电机额定电流设置，
   靠驱动板限流，勿直接超压驱动。
3. 未接动力电源时电机不转，但串口协议、状态机、IO 信号可完整测试。
4. 调试用串口监视器退出后若板子"不运行"，是 RTS 线把芯片按在了复位里，
   断电重启或显式释放 RTS/DTR 即可。
5. 电机螺杆不得承受径向负载；接线 A+红 A-绿 B+黄 B-蓝。

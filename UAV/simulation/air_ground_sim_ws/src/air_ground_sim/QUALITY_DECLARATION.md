# Software quality declaration

This pre-1.0 package does **not** claim a REP-2004 Quality Level or a functional-safety certification. It uses semantic pre-release versioning, declares its public ROS topic/service contracts in the deployment documents, runs automated unit/configuration/system tests, and records known external validation gates in `PRODUCTION_READINESS.md`.

The target for a 1.0 release is a documented stable API, supported-platform policy, changelog and deprecation policy, measured coverage, dependency quality review, HIL evidence, vulnerability-response process, and reproducible signed release artifacts. REP-2004 is available at <https://www.ros.org/reps/rep-2004.html>.

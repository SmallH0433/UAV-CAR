# 2026-10-06 本机加速度计六面校准记录

设备为本项目这架飞机的 Pixhawk1，固件 ArduCopter 4.7.0（`1511f271`）。同目录的 `pixhawk1_accel_20261006.param` 是这台实机的校准结果快照，仅用于留档与人工核对，不应自动加载，也不适用于其他飞控或机架。

本次在拆桨、上锁状态下，通过 USB 连接完成了实际六面摆放与采样，收到飞控的六面校准 `SUCCESS`，随后逐项读回参数。按飞控提示完全断电再上电后，再次读取完整参数；下列 16 项与校准后读值逐一比较，float32 位模式全部一致。两列 `.param` 文件也通过了离线解析及 float32 往返校验。

快照仅包含两颗加速度计的三轴偏移、三轴比例（12 项），两项加速度计校准温度，以及 `AHRS_TRIM_X/Y`（共 16 项）。例如主加速度计的 `INS_ACCOFFS_Z` 从 `-0.14495997` 变为 `+0.28889942`，`INS_ACCSCAL_Z` 从 `0.99398708` 变为 `0.99823052`。这些值由本次实机校准产生，不是通用调参建议。

重启后进行了 60 秒 USB 地面静置观测：60 次心跳均为上锁、60 次地面状态均为 `ON_GROUND`；179 个本地位置样本的垂速（向上为正）中位数为 `+0.00623 m/s`，范围为 `-0.01893～+0.02553 m/s`；估计高度首尾变化约 `+0.070 m`，全程跨度约 `0.121 m`。两颗 IMU 的加速度模中位数分别为 `1.00300 g`、`1.00103 g`。这段记录未再出现“校准需重启”或“EKF roll/pitch inconsistent”提示。

这些数据说明重启后的静置垂直估计有所改善，不构成空中控制效果或零垂速爬升问题已解决的证明。USB 供电、温度、预热时间和估计器重启都会影响前后比较；本次没有修改 PID 或 EKF 高度源，也没有通过试飞验证这次校准。

完整参数对比另外观察到 `BRD_SD_SLOWDOWN` 从 `3` 变为 `2`；本次脚本没有写入该参数，其变化原因未在本次校准中确认。`BARO1_GND_PRESS`、`STAT_BOOTCNT`、`STAT_RUNTIME` 及启动陀螺仪校准相关值也有变化。这些不属于上述 16 项快照，均未混入文件。

包含 1015 项参数的前后完整备份、原始遥测、校准握手记录及持久化逐项校验结果只保存在本机，不随本目录发布。
